# Working on Nancy's game

Read [the production plan](docs/production-plan.md) before planning updates. It
records the user's agreed six-stage sequence, current milestone, acceptance
criteria, and verification results. Update it when delivering a milestone; do
not mark later stages complete because some of their features already exist.

- Keep the room's three main buttons and focused secondary panels.
- Use the actual Blender Kitty model and the existing React/TypeScript stack.
- Preserve existing progress, shared equipment, and classic save compatibility.
- Keep the art bright, pastel, nostalgic, and free of film grain.
- The user explicitly authorized an assistant-written letter to Nancy. The ready
  letter is in `dist/letter.js`; keep it editable and honor later personal edits.
  Do not invent specific shared memories or the author's name.
- Test the affected interactions and distinguish browser emulation from testing
  on a physical phone or Mac. Record limitations honestly.
- Follow the user's current instructions if they change this plan.
